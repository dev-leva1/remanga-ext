## Ключевые решения

### Архитектура
Выбрана прагматичная 3-уровневая архитектура:
- **Core** - базовая инфраструктура (Config, ApiClient)
- **Features** - бизнес-логика (ChapterManager, AutoLiker)
- **UI** - пользовательский интерфейс (SettingsPanel, Notifications)

### Технологии
- Vanilla JavaScript (ES6+)
- Tampermonkey API (GM.getValue, GM.setValue, GM.xmlHttpRequest)
- Нативные Web APIs (MutationObserver, Promises, async/await)

### Паттерны
- Singleton для Config
- Dependency Injection для компонентов
- Observer pattern для DOM изменений
- Factory pattern для создания UI элементов
