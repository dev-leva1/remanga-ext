# Данные и разрешения

[← Документация](README.md)

Это техническое описание наблюдаемого поведения текущего кода, а не обещание отсутствия рисков или формальная политика обработки персональных данных сторонними сервисами.

## Userscript

| Данные / разрешение | Назначение |
| --- | --- |
| `@match https://remanga.org/*` | Выполнение скрипта на страницах ReManga |
| `GM.getValue`, `GM.setValue` | Настройки, статистика, время проверки обновлений, состояние автокомментариев и лимитера |
| `GM.xmlHttpRequest` | Запросы к API ReManga и проверка версии userscript |
| Cookie `token` ReManga | Извлекается API-клиентом для авторизации запросов к api.remanga.org от имени пользователя |
| `localStorage` | Флаг локальной отладки `remanga_ext_debug` |

В заголовке userscript разрешены подключения к `api.remanga.org` и `ext.nexee.ru`. Последний используется для обновлений. Исходники API-клиента и механизма обновлений: [ApiClient.js](../src/core/ApiClient.js), [UpdateChecker.js](../src/core/UpdateChecker.js).

Автоматизация изменяет состояние аккаунта (лайки, отметки прочитанного, комментарии) через API ReManga. Операции выполняются в соответствии с включёнными функциями и действиями пользователя. Не передавайте токены другим людям и не публикуйте сырые отладочные данные.

## Обратная связь

При обращении через расширение пользователь может выбрать технический контекст: версию, браузер и URL страницы. Интерфейс формирует команду/ссылку для Telegram-бота. Бот обрабатывает обращения и сохраняет их, включая предоставленный контекст и идентификаторы, необходимые для работы, в PostgreSQL. Администраторы получают уведомления об обращениях.

Перед отправкой проверьте, нет ли в тексте, URL или вложениях личных данных. Не указывайте cookies или токены. Реализация: [FeedbackButton.js](../src/ui/FeedbackButton.js), [feedback-bot](../feedback-bot/README.md).

## Сайт установки

Лендинг ext.nexee.ru содержит подключение Яндекс Метрики и внешних шрифтов Google Fonts ([исходный HTML](../dist/index.html)). Посещение сайта может инициировать обращения к этим сервисам. Это отдельный контекст от работы userscript в ReManga.

## Контроль данных

Настройки и статистику можно сбросить через интерфейс расширения; отключение или удаление скрипта выполняется в менеджере userscript. Для очистки всего локального хранилища используйте средства своего менеджера. По вопросам серверных данных обращения свяжитесь с сопровождающим через [бот обратной связи](https://t.me/remanga_extension_bot).

Сообщение об уязвимости: [SECURITY.md](../SECURITY.md).
