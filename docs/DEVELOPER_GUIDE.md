## Окружение

Для локальной работы используйте поддерживаемый Node.js LTS и npm. Исторический минимальный ориентир проекта — Node.js 18+, npm 9+; не используйте неподдерживаемую версию Node.js для публичного развёртывания. Для браузерной проверки нужен менеджер userscript. Feedback-bot требует собственных зависимостей, PostgreSQL и тестового Telegram-бота.

```bash
git clone https://github.com/dev-leva1/remanga-ext.git
cd remanga-ext
npm ci
npm run lint
npm run build
node --check dist/remanga-extension.user.js
```

| Команда | Назначение |
| --- | --- |
| `npm run build` | Сборка userscript |
| `npm run build:userscript` | Альтернативная команда сборки userscript |
| `npm run lint` | ESLint для src |
| `npm run lint:fix` | Автоисправление ESLint; проверяйте diff |

Сборщик `build.js` объединяет исходники по манифесту и формирует заголовок userscript из версии и CHANGELOG. Результат: `dist/remanga-extension.user.js`. Не вносите исправления только в dist.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/main.js` | Bootstrap и жизненный цикл |
| `src/core/` | Config, API, статистика, обновления, SPA-навигация |
| `src/features/` | Автоматизация и функции интерфейса |
| `src/ui/` | Настройки, уведомления, обратная связь, стили |
| `src/utils/` | Валидация, DOM, логирование, changelog |
| `feedback-bot/` | Отдельный Telegram-сервис |
| `dist/` | Собранный userscript и логотип |
| `docs/` | Документация |

## Проверки

Запустите сборку, lint и проверку синтаксиса. Убедитесь, что изменения сгенерированных файлов ожидаемы:

```bash
git diff --stat
git diff --check
```

Вручную установите локально собранный файл в тестовый профиль браузера. Используйте собственный аккаунт, ограниченный набор глав и допустимые правилами сайта действия.

- [ ] Настройки открываются, сохраняются и сбрасываются без обязательной перезагрузки.
- [ ] SPA-переходы не оставляют старые overlay, observers и дублирующиеся кнопки.
- [ ] Массовые операции показывают корректный прогресс, учитывают ошибки и пропуски.
- [ ] Автолайк и автокомментарии по умолчанию выключены; изменение настройки корректно применяется.
- [ ] Функции каталога, обложек и профилей работают только в подходящих контекстах.
- [ ] Обратная связь позволяет выбрать технический контекст без публикации секретов.
- [ ] Проверка обновлений корректно сравнивает версии.

При необходимости включите отладку в консоли браузера:

```javascript
localStorage.setItem('remanga_ext_debug', 'true');
```

После проверки выключите её: `localStorage.removeItem('remanga_ext_debug')`. Не публикуйте логи, содержащие токены или данные пользователей.

В корневом package.json нет команды автоматизированного тестового набора; не подменяйте runtime smoke-проверку успешным lint. В PR перечисляйте фактически выполненные проверки.
