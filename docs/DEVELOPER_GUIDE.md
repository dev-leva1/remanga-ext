# Developer Guide

Этот документ описывает базовый процесс разработки, локальной проверки и выпуска userscript-файла `dist/remanga-extension.user.js`.

## Минимальные требования

- **Node.js 18+** (рекомендуется LTS).
- **npm 9+** (обычно идет вместе с Node.js).
- **Tampermonkey** в браузере (Chrome/Firefox/Edge) для ручной проверки userscript.
- Доступ к аккаунту на [remanga.org](https://remanga.org) для проверки сценариев, связанных с авторизацией.

## Основные команды

Выполняются из корня репозитория:

```bash
npm run build
npm run lint
npm run lint:fix
```

- `npm run build` — собирает финальный userscript в `dist/remanga-extension.user.js`.
- `npm run lint` — проверяет `src/**/*.js` через ESLint.
- `npm run lint:fix` — запускает ESLint с автоисправлением безопасных проблем.

## Структура `src/` и ключевые модули

```text
src/
├── core/       # Базовые сервисы (конфиг, API, статистика, проверка обновлений)
├── features/   # Функциональные сценарии (главы, автолайк, UI-фичи профиля/хедера)
├── ui/         # UI-слой (страницы и панели настроек, уведомления, стили)
├── utils/      # Вспомогательные утилиты
└── main.js     # Точка входа и инициализация
```

Назначение ключевых директорий:

- `src/core/` — инфраструктурный слой: конфигурация, взаимодействие с API, служебные сервисы.
- `src/features/` — бизнес-логика пользовательских фич.
- `src/ui/` — рендер и поведение интерфейсных компонентов расширения.
- `src/utils/` — переиспользуемые утилиты без доменной логики.

## Частые точки входа

При большинстве задач сначала проверьте эти файлы:

- `src/main.js` — главный bootstrap: инициализация модулей и жизненного цикла скрипта.
- `src/core/Config.js` — значения по умолчанию, чтение/запись пользовательских настроек.
- `src/features/ChapterManager.js` — массовые операции с главами, отметка прочитанного, лайки.
- `src/ui/SettingsPage.js` — UI страницы настроек, привязка контролов к `Config`.

## Сценарий локальной проверки userscript

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Соберите userscript:
   ```bash
   npm run build
   ```
3. Откройте `dist/remanga-extension.user.js` и установите/обновите скрипт в Tampermonkey.
4. Перейдите на `remanga.org`, авторизуйтесь и проверьте критичные сценарии:
   - Страница чтения: автолайк и автоотметка прочитанного (при включенных настройках).
   - Страница списка глав: кнопки массового лайка и массовой отметки.
   - Страница настроек: изменение опций и сохранение между перезагрузками.
5. При необходимости включите debug-логи:
   ```javascript
   localStorage.setItem('remanga_ext_debug', 'true');
   ```

## Release-flow: обновление `dist/remanga-extension.user.js`

1. Внести изменения в `src/` и связанные документы.
2. Обновить версию в `package.json` (по принятому в проекте semver-подходу).
3. Запустить проверки:
   - `npm run lint`
   - `npm run build`
4. Убедиться, что `dist/remanga-extension.user.js` действительно пересобран и содержит актуальную версию/код.
5. Провести ручную smoke-проверку в Tampermonkey на remanga.org.
6. Обновить релевантную документацию (`README.md`, `docs/*`, changelog при наличии).
7. Сформировать коммит, включив изменения в `src/`, `dist/` и документации.

## Чеклист перед релизом

- [ ] Версия обновлена в `package.json`.
- [ ] Выполнена сборка: `npm run build`.
- [ ] Проверены критичные функции (автолайк, отметка прочитанного, массовые действия, настройки).
- [ ] Обновлена документация (минимум `README.md` и/или профильные файлы в `docs/`).
