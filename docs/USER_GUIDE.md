# Руководство пользователя

[← Документация](README.md)

## Установка и удаление

Установите Tampermonkey или Stay по [инструкции в README](../README.md#установка). Откройте [файл установки](https://raw.githubusercontent.com/dev-leva1/remanga-ext/main/dist/remanga-extension.user.js) и подтвердите установку. Если автоматическое открытие не работает, скачайте файл и импортируйте его в менеджер или создайте новый скрипт, вставьте код и сохраните.

После установки откройте remanga.org и войдите в свой аккаунт. Чтобы отключить или удалить расширение, воспользуйтесь интерфейсом менеджера userscript. Включайте только один экземпляр расширения.

## Настройки

Кнопка Remanga Enhanced в шапке сайта открывает окно настроек.

| Вкладка | Возможности |
| --- | --- |
| Автоматизация | Автолайк, автокомментарий, пропуск уже обработанных глав, размер batch |
| Интерфейс | Темы и блоки профиля, индикатор чата, подсветка гильдий, тултипы, случайный тайтл, обложки |
| Общее | Уведомления, проверка обновлений, статистика, обратная связь |

Автолайк и автокомментарии выключены по умолчанию. Настройки сохраняются в хранилище менеджера userscript и применяются без обязательной перезагрузки страницы.

## Работа с главами

На странице списка глав доступны массовая отметка прочитанного и массовые лайки. При выполнении отображается прогресс. При включённом пропуске обработанных глав расширение старается не повторять обнаруженные действия.

Автолайк действует в ридере при включённой опции. Автокомментарий требует непустого текста и отдельного включения; отправка привязана к достижению секции комментариев. В реализации предусмотрены дедупликация и ограничение частоты. Не используйте функцию для спама, повторяющихся нежелательных комментариев или накрутки показателей.

## Интерфейс

- На страницах каталога (`/catalog` и исторический `/manga`) предусмотрена кнопка случайного тайтла.
- На странице тайтла клик по обложке открывает полноэкранный просмотр, если функция включена.
- На поддерживаемых страницах форума и гильдий доступна подсветка.
- Тултипы профилей появляются на поддерживаемых элементах сайта при включённой настройке.

## Обновления

Встроенная проверка получает [собранный userscript](https://raw.githubusercontent.com/dev-leva1/remanga-ext/main/dist/remanga-extension.user.js) из ветки `main` через GitHub Raw с интервалом между автоматическими проверками 12 часов. Ручная проверка доступна во вкладке «Общее». GitHub Releases служат журналом версий и архивом исходников.

Если установлена версия до v1.8.1, один раз откройте новую ссылку установки вручную. Подтвердите обновление существующего скрипта (имя и namespace сохранены), не удаляя его заранее. Проверьте, что установлена только одна копия и менеджер использует GitHub Raw для обновлений. Если менеджер не распознаёт существующую установку, воспользуйтесь его функцией импорта/резервного копирования настроек.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Нет кнопки настроек | Включён ли userscript; открыта ли страница remanga.org; не блокирует ли браузер запуск userscript |
| Нет нужной функции | Включена ли настройка; поддерживается ли текущая страница |
| Ошибка API | Авторизация в ReManga, состояние сайта, версия расширения |
| Массовые действия обрабатывают не все главы | Загружены ли главы, есть ли ограничения или ошибка страницы; не повторяйте запросы бесконечно |
| После обновления поведение не меняется | Версия в настройках, наличие второй копии скрипта, состояние менеджера |
| Проблема остаётся | Создайте [Issue](https://github.com/dev-leva1/remanga-ext/issues/new/choose) с версией, браузером и шагами воспроизведения |

Не прикладывайте cookies, токены, полный сетевой лог или необезличенный скриншот. Подробнее о данных: [PRIVACY.md](PRIVACY.md).
