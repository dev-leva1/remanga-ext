### Индикатор непрочитанных сообщений (Задача #3)
- **Селектор**: `a[href*="/chat"]` содержит button с текстом (число)
- **Структура**: 
  ```
  <a href="/chat">
    <button>3</button>  <!-- Число = количество непрочитанных -->
  </a>
  ```
- **Решение**: Скрывать текст внутри button через CSS или удалять элемент

### Кастомные темы (Задача #1)
- **Фон body**: `rgb(19, 20, 22)` - стандартный темный фон
- **Найдено**: 8 style тегов на странице
- **Inline стили**: 63 элемента с атрибутом style
- **Предположение**: Кастомные темы могут применяться через:
  - Inline стили на элементах профиля
  - Отдельные `<style>` теги, добавленные пользователем
  - CSS переменные или классы

**Решение для блокировки**:
- Использовать MutationObserver для отслеживания добавления `<style>` тегов
- Удалять или переопределять inline стили на элементах профиля
- Добавить настройку в Config для включения/отключения

## Кнопка настроек в header (Задача #5)

### Текущая реализация:
```javascript
// src/ui/SettingsPanel.js:65-88
button.style.cssText = buttonStyles('icon') + `
  margin: 0 ${DESIGN_TOKENS.spacing.xs};
`;
```

### Проблема:
- Используется `buttonStyles('icon')` с `background: transparent`
- Нет постоянной подложки как у других кнопок

### Решение:
- Изучить стили других кнопок в header (Закладки, Чат, Уведомления)
- Добавить постоянный фон: `background: rgba(255, 255, 255, 0.05)` или подобный
- Сохранить hover эффект

## Архитектурные решения

### Общий подход:
1. **Модульность**: Каждая задача = отдельный feature класс
2. **Конфигурация**: Все настройки в Config с defaults
3. **UI**: Новая страница настроек вместо модального окна
4. **Совместимость**: Сохранить существующую архитектуру

### Приоритет реализации:
1. Задача #5 (подложка кнопки) - самая простая
2. Задача #3 (индикатор чата) - простая
3. Задача #2 (скрытие блоков) - средняя сложность
4. Задача #1 (блокировка тем) - средняя сложность
5. Задача #4 (страница настроек) - самая сложная
