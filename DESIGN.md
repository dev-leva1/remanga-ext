# Design System: Remanga Enhanced

## 1. Визуальный язык

Минималистичный интерфейс, который выглядит естественным дополнением ReManga. Сохраняйте нейтральную тёмную палитру, монохромный логотип и спокойную визуальную иерархию. Избегайте декоративных эффектов без функциональной цели.

Источник действующих токенов — [src/ui/styles.js](src/ui/styles.js). Документация не должна подменять реализацию. Логотип проекта — [dist/logo.svg](dist/logo.svg).

## 2. Типографика и компоненты

- Exo 2 с системным fallback; базовый размер 14 px, дополнительные размеры 12–24 px.
- Нейтральные кнопки с pill-радиусом; вторичные и иконковые действия отличаются по визуальному весу.
- Модальные окна, overlay и toast используют общие helpers из styles.js.
- Настройки разделены на автоматизацию, интерфейс и общие параметры; не смешивайте несвязанные действия.
- Операции с последствиями для аккаунта должны иметь понятные подписи, состояние прогресса и результат.

## 3. Доступность и поведение

Стремитесь к WCAG AA по контрасту, читаемости и фокус-состояниям. Поддерживайте клавиатуру и узкие экраны, не полагайтесь только на hover или цвет. Уважайте reduced motion. При SPA-переходах освобождайте observers, listeners и overlay; не дублируйте элементы интерфейса.

## 4. Публичное оформление

GitHub README и документация используют существующий логотип, краткое описание, понятную установку и навигацию. Не заявляйте гарантии безопасности, совместимости или отсутствия санкций без проверок.
